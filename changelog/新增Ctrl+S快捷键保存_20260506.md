# 新增 Ctrl+S / Cmd+S 快捷键保存

**时间**：2026-05-06

---

## 需求描述

在编辑笔记时按下 `Ctrl+S`（Windows）或 `Cmd+S`（Mac）快捷键，直接保存笔记，无需点击保存按钮。

---

## 改动文件

### `src/client/views/NoteEditorView.vue`

- 新增 `handleKeyDown` 函数，监听 `Ctrl+S` / `Cmd+S`，拦截浏览器默认保存页面行为并调用 `saveNote()`
- 在 `onMounted` 中注册 `window.addEventListener('keydown', handleKeyDown)`
- 在 `onBeforeUnmount` 中移除监听器，防止内存泄漏
- 保存进行中时（`saving.value === true`）不会重复触发

```diff
+// Ctrl+S / Cmd+S 快捷键保存
+function handleKeyDown(e: KeyboardEvent) {
+  if ((e.ctrlKey || e.metaKey) && e.key === 's') {
+    e.preventDefault();
+    if (!saving.value) {
+      saveNote();
+    }
+  }
+}

 onMounted(async () => {
+  window.addEventListener('keydown', handleKeyDown);
   // ...
 });

+onBeforeUnmount(() => {
+  window.removeEventListener('keydown', handleKeyDown);
+});
```
